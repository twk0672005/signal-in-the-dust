# Data boundaries
- Existing Expedition/Activities/observedEcology own game truth. Free exploration alters explicit eligibility/closing flow, not fake completion flags.
- LaunchIntent: new|continue plus locale/quality, consumed once; failed restore preserves old progress.
- GuideContext: phase/region/position/heading, interaction readiness and existing ecology/encounter snapshots.
- Whisper: localized key, priority, dedupe key, expiry/cooldown and optional sound; no gameplay mutation.
- VisualAsset: stable ID/source script/blend/hash, derived GLB/textures/hash, units/axes/bounds, clips/skin, channels/alpha, provenance and measured cost.
- ReferenceAnchor: concept hash, named characteristic/view, required capture, reviewer finding; numeric similarity requires an actual rubric.
